說明與技術文件

快速上手

  • 新增地點：點擊地圖空白處 →「新增地點」；或按上方「新增地點」輸入座標，也可以用「從地圖選點」直接點地圖取座標。
  • 編輯／刪除：點地圖上的圖釘或列表卡片，在資訊視窗中操作。
  • 造訪打卡：列表卡片右側的方塊勾選後，圖釘會變灰，代表已造訪。
  • 篩選：側欄可依「國家」下拉選單與「分類」色塊篩選，並可關鍵字搜尋；地圖與列表會同步過濾。
  • 定位：地圖右上的準心按鈕會請求瀏覽器定位並飛到你的位置（僅在本機運算，不會上傳）。
  • 日夜圖層：切換深色／標準地圖底圖，選擇會被記住。

技術架構

本頁是單一 HTML 靜態檔：介面為原生 HTML＋CSS＋JavaScript，地圖由 Leaflet 繪製，底圖瓦片來自 OpenStreetMap／CARTO。沒有任何後端伺服器——所有資料只存在你的瀏覽器裡。

資料儲存：IndexedDB

所有資料儲存在瀏覽器的 IndexedDB（資料庫名稱 ptm-db），共三個 Object Store：

Object Store欄位說明
placesid, name, country, category, lat, lng, notes, visited, createdAt, updatedAt地點主檔，id 為主鍵
categoriesid, name, color, protected, createdAt分類（含圖釘顏色）
countriesid, name, code, createdAt國家（code 為選填 ISO 兩碼）

匯入／匯出（JSON）

「匯出」會把全部資料打包成 JSON 檔下載；「匯入」時可選擇合併（依 id 覆蓋同名資料、補上不存在的項目）或覆蓋（清空後重建）。檔案格式範例：

{
  "app": "pixel-travel-map",
  "version": 1,
  "exportedAt": "2026-10-07T00:00:00.000Z",
  "categories": [ { "id": "cat-nature", "name": "自然", "color": "#00e436" } ],
  "countries":  [ { "id": "ctry-a1b2c3d4", "name": "日本", "code": "JP" } ],
  "places":     [ { "id": "e5f6a7b8", "name": "富士山", "category": "cat-nature",
                    "country": "ctry-a1b2c3d4", "lat": 35.3606, "lng": 138.7274,
                    "notes": "日本最高峰", "visited": false,
                    "createdAt": 1760000000000, "updatedAt": 1760000000000 } ]
}

持久化儲存

瀏覽器在儲存空間不足時，可能自動清除網站的 IndexedDB 資料。本頁會在你第一次儲存地點後，透過 navigator.storage.persist() 向瀏覽器申請「持久化」，獲准後資料會被優先保留。Chrome 會自行評估是否授予（例如已安裝到主畫面的網站較容易通過）；你也可以隨時在「設定 → 儲存空間」查看狀態並手動申請。

加入主畫面

偵測到瀏覽器支援安裝時，底部會出現提示橫幅；iOS 請用 Safari「分享 → 加入主畫面」。
技術細節：本頁以動態產生的 manifest（Blob URL＋Canvas 繪製的像素圖示）嘗試觸發 beforeinstallprompt。由於單一 HTML 檔無法附帶獨立的 manifest.json，部分瀏覽器版本可能不會主動彈出提示——此時改用瀏覽器選單的「安裝應用程式／加入主畫面」即可，功能完全不受影響。若想要完整 PWA 體驗，可在 repo 補上一個真實的 manifest.json 並在 <head> 加入 <link rel="manifest" href="manifest.json">。

部署到 GitHub Pages

  1. 在 GitHub 建立一個公開的 Repository。
  2. 上傳本檔案，命名為 index.html。
  3. Repository Settings → Pages → Branch 選 main、目錄 / (root) → Save。
  4. 等待 1–2 分鐘，以 https://<帳號>.github.io/<repo>/ 開啟。

隱私

沒有帳號、沒有追蹤、沒有伺服器：地點資料只存在你的裝置上，匯出檔案之前不會離開瀏覽器。地圖瓦片與像素字型由第三方（OpenStreetMap／CARTO／Google Fonts）提供。

📖 TECHNICAL DOCUMENTATION

1. Data Model

Each cell value is stored as an integer 0-3, mapping to the cycle: 0:"☐" → 1:"☑" → 2:"♥️" → 3:"☒". Config is { layers, columns, units }. When dimensions shrink, excess data is discarded; when growing, new cells default to 0.

2. IndexedDB Schema

Database unitcheck-db, object store state (keyPath id). Two records: config and data, where data.values is a flat object keyed "layer:col:unit" → 0-3. All writes are transactional (readwrite) and debounced; every click persists immediately.

3. Persistent Storage

On first load the app calls navigator.storage.persist() to request persistent storage, preventing the browser from evicting IndexedDB data under storage pressure. Status is shown via navigator.storage.persisted().

4. JSON Import / Export

Export serialises { version, config, data } and downloads it as unit-check-YYYYMMDD-HHMMSS.json. Import validates the JSON structure, clamps values to 1-50, rebuilds the grid and merges saved cell states.

5. Add to Home Screen (A2HS)

The app listens to beforeinstallprompt. When fired, the event is saved and an install banner appears; clicking it triggers prompt(). This is a progressive enhancement — on GitHub Pages it works best alongside a PWA manifest.json and service worker.

6. Sorting

The table can be re-ordered: Columns Descending / Units Ascending is the default view, matching the spec. Buttons allow toggling column and unit direction. Sorting affects only display order; stored coordinates are stable.

7. Responsive Design

The table sits in an overflow-x: auto scroll container. Buttons use clamp() font sizing and a 44px minimum touch target. The config panel uses a CSS grid that reflows on narrow screens.

8. 8-bit Pixel Style

Monospace type, hard box-shadow offsets (no blur) for chunky borders, a CRT-style scanline/grid background, and a 4-colour retro palette (navy, gold, red, mint).

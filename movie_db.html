◈ 資料管理 ◈

所有收藏、觀看紀錄與快取均儲存於瀏覽器 IndexedDB。

可將資料匯出為 JSON 備份，或從 JSON 檔案匯入還原。

◈ 技術架構說明 ◈

1. 前端：單一 HTML 檔案（SPA 模式），原生 JavaScript + CSS Grid 響應式佈局，無任何框架依賴，可直接部署到 GitHub Pages。

2. 資料來源：透過 fetch 呼叫 TMDB REST API（/discover/movie、/search/movie、/movie/{id}）。※ 注意：本示範將 API Key 放在前端，正式部署建議改用代理服務隱藏 Key。

3. 離線資料庫：使用 IndexedDB（非同步、容量大、支援物件儲存），存放三個 store：movies（詳情快取）、favList（收藏）、seenList（觀看紀錄）。

4. 持久化：呼叫 navigator.storage.persist()，要求瀏覽器承諾在儲存壓力下不自動清除本站資料（預設 IndexedDB 可能被「逐出」eviction）。狀態可由 navigator.storage.persisted() 查詢。

5. 匯入匯出：匯出 = 讀取所有 store → JSON.stringify → Blob + URL.createObjectURL 觸發下載。匯入 = FileReader 讀取 → JSON.parse → 逐筆 put 回資料庫。

6. A2HS：監聽 beforeinstallprompt 事件，延遲顯示自訂安裝橫幅；按下後呼叫保留的 prompt()。iOS Safari 不支援此事件，因此提供額外的操作指引。

7. 圖片：海報使用 TMDB 圖片 CDN，設定 loading="lazy" 懶加載；CSS image-rendering:pixelated 保持像素感。

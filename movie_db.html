◈ 資料管理 ◈

所有收藏、觀看紀錄與快取均儲存於瀏覽器 IndexedDB。

可將資料匯出為 JSON 備份，或從 JSON 檔案匯入還原。

◈ 技術架構說明 ◈

1. 前端：單一 HTML 檔案（SPA 模式），原生 JavaScript + CSS Grid 響應式佈局，無任何框架依賴，可直接部署到 GitHub Pages。

2. 資料來源：透過 fetch 呼叫 TMDB REST API。/discover/movie 用於探索篩選（支援類型、年份、國家、排序）；/search/movie 用於關鍵字搜尋，並以 region 參數調整結果排名。※ 注意：API Key 放在前端會公開可見，建議在 TMDB 後台限制網域。

3. 國家/地區篩選原理：探索模式下使用 with_origin_country（ISO 3166-1 兩位代碼，如 TW、JP、KR），篩選「該國出品」的作品；搜尋模式下使用 region，讓結果優先顯示該地區常用的譯名與上映資訊。

4. 離線資料庫：使用 IndexedDB，三個 store：movies（詳情快取）、favList（收藏）、seenList（觀看紀錄）。

5. 持久化：navigator.storage.persist() 要求瀏覽器承諾在儲存壓力下不自動清除本站資料。

6. 匯入匯出：匯出 = 讀取所有 store → JSON.stringify → Blob 下載。匯入 = FileReader → 驗證 → 逐筆 put（upsert 合併）。

7. A2HS：監聽 beforeinstallprompt，攔截原生提示改顯示像素風橫幅；manifest 以 data URI 內嵌於單一檔案中。iOS Safari 顯示手動操作指引。

8. 圖片：海報使用 TMDB 圖片 CDN，loading="lazy" 懶加載。

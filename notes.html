★ TECHNICAL DETAILS (技術說明)

► Storage (儲存機制)：本應用使用 IndexedDB 儲存筆記資料。不同於 localStorage 限制 5MB，IndexedDB 提供更大儲存空間與非同步 API，適合儲存結構化資料。

► Persistence (持久化)：透過 navigator.storage.persist() 申請持久化儲存。瀏覽器通常會在空間不足時清除資料，持久化可保護資料不被自動清除（需使用者授權或互動後觸發）。

► A2HS (加入主畫面)：透過 PWA beforeinstallprompt 事件實作 Add to Home Screen 提示，讓使用者可將應用安裝至桌面。

► Data Format (資料格式)：匯入/匯出使用標準 JSON 格式，結構包含：id, title, content, tags, createdAt, updatedAt。

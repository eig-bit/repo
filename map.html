地圖技術說明

渲染引擎
使用 Leaflet.js v1.9.4 開源地圖庫，以 Canvas 模式渲染（preferCanvas）， 提升大量標記時的繪製效能。瓦片來源採用 OpenStreetMap 與 CARTO， 共四種圖層可循環切換。
資料儲存
場所與類型資料皆儲存於 IndexedDB （markers 與 types 兩個物件儲存庫）。類型支援自訂名稱與顏色， 標記圖示會即時套用類型顏色。啟動時呼叫 navigator.storage.persist() 申請持久化儲存。
篩選與管理
「場所列表」提供類型篩選（可單選類型或顯示全部）。 工具列「🏷️類型」開啟類型管理： 可新增、編輯、刪除類型；刪除類型時，其所屬場所會自動改歸第一個類型。
匯入 / 匯出
以 JSON 格式匯出全部場所與類型（含版本號與匯出時間）， 匯入時自動驗證格式、補齊缺失類型並重編 ID。
其他技術
・定位：Geolocation API（高精度模式）
・安全：escapeHtml 防 XSS 注入
・響應式：768px 斷點，側欄可摺疊（狀態記憶）
・風格：8-bit 像素風 UI，字體 Press Start 2P

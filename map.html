地圖技術說明

渲染引擎
使用 Leaflet.js v1.9.4 開源地圖庫，以 Canvas 模式渲染（preferCanvas）， 提升大量標記時的繪製效能。瓦片來源採用 OpenStreetMap 與 CARTO， 共四種圖層可循環切換（街道 / 暗黑 / 明亮 / 地形）。
資料儲存
場所資料儲存於 IndexedDB（物件儲存庫名稱：markers）， 支援索引查詢（lat / lng / type / name）。啟動時呼叫 navigator.storage.persist() 申請持久化儲存， 防止瀏覽器在儲存空間不足時自動清除資料。
匯入 / 匯出
以 JSON 格式匯出全部場所（含版本號與匯出時間）， 匯入時自動驗證格式並重編 ID，避免主鍵衝突。適合備份與跨裝置搬移。
響應式設計
採用 流體佈局 + 媒體查詢（768px 斷點）： 桌面版為「地圖 + 右側欄」，行動版側欄改為底部抽屜， 並自動調整縮放級別與控制項大小，支援觸控手勢（雙指勢（雙指縮放、單指拖曳）。
其他技術
・定位：Geolocation API（高精度模式）
・加入主畫面：教學式提示（偵測 iOS / Android / 桌面平台）
・安全：escapeHtml 防 XSS 注入
・風格：8-bit 像素風 UI，字體 Press Start 2P

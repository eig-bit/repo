TECH NOTES (click to expand)

Architecture

A single zero-dependency static HTML file. All logic runs client-side and it can be hosted directly on GitHub Pages.

IndexedDB Storage

All game data is stored in IndexedDB (database GameVaultDB, object store games, key path id). Compared with localStorage it is asynchronous, larger, and structured.

const db  = await openDB();
await dbPut(game);        // put (same id overwrites)
const all = await dbGetAll();
await dbDelete(id);

navigator.storage.persist()

Browsers may evict IndexedDB data under storage pressure ("best-effort" storage). Calling navigator.storage.persist() requests persistent storage; once granted, data will not be auto-cleared. The PERSIST button in the header requests it and reports status via navigator.storage.persisted() and navigator.storage.estimate().

iTunes Lookup API

When you paste a link, the page extracts the App ID and region, then calls Apple's free iTunes Lookup API (no key, CORS-friendly):

https://itunes.apple.com/lookup?id={APP_ID}&country={REGION}

It returns icon (artworkUrl512), name, developer, rating, price, description, genre and screenshots. Note: the API is rate-limited (~20 calls/min per IP).

Pagination & Filtering

Search / filter / sort run fully in memory, then the list is paginated (12 cards per page).

JSON Import / Export

Export downloads all data as a dated JSON file. Import merges: entries with the same App ID are updated, not duplicated.

Add to Home Screen

Chrome/Edge: the beforeinstallprompt event triggers the bottom banner. iOS Safari does not support this event, so a hint banner is shown instead (Share > Add to Home Screen). For full PWA installability, add a real manifest.json and Service Worker when deploying.

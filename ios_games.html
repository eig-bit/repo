📚 技術說明（點擊展開）

🏗️ 架構總覽

本頁面是一個零依賴的單一 HTML 檔案靜態網頁，所有邏輯在瀏覽器端執行，可直接部署到 GitHub Pages。

💾 IndexedDB 資料儲存

所有遊戲資料儲存在瀏覽器的 IndexedDB（資料庫名稱 GameVaultDB，物件倉儲 games，主鍵為 App ID）。相比 localStorage，IndexedDB 支援非同步、容量更大、結構化資料。

const db = await openDB();            // 開啟資料庫
await db.put('games', gameObj);      // 寫入（同 ID 會覆蓋）
const all = await db.getAll('games'); // 讀取全部
await db.delete('games', appId);      // 刪除

🔒 navigator.storage.persist() 持久化

瀏覽器在儲存空間不足時，可能自動清除 IndexedDB 資料（「盡力而為」儲存）。呼叫 navigator.storage.persist() 可向瀏覽器申請「持久化儲存」，通過後資料不會被自動清除。點擊上方「💾 持久化儲存」按鈕即可申請，並可用 navigator.storage.persisted() 查詢目前狀態。也可透過 navigator.storage.estimate() 查看已用/可用空間。

🔗 iTunes Lookup API 自動擷取

貼上連結後，頁面會解析出 App ID，並呼叫蘋果官方的 iTunes Lookup API（免金鑰、免 CORS 設定）：

https://itunes.apple.com/lookup?id={APP_ID}&country=hk

API 回傳 JSON，包含：圖標 artworkUrl512、名稱 trackName、開發商 artistName、評分 averageUserRating、價格 formattedPrice、描述 description、類型 primaryGenreName、截圖 screenshotUrls 等。連結中的地區碼（如 hk、us）會被保留，確保價格與語言正確。

📄 分頁與篩選

所有篩選／排序／搜尋都在記憶體中處理後重新分頁，每頁預設顯示 12 張卡片。搜尋同時比對名稱、開發商與標籤。

📥📤 JSON 匯入／匯出

匯出會將全部資料序列化為 JSON 檔案下載（檔名含日期）。匯入支援「合併」模式：相同 App ID 的資料會被覆蓋更新，不會產生重複。匯入格式：

[ { "id": "6762813110", "name": "Sifu", ... }, ... ]

📱 Add to Home Screen（A2HS）

頁面偵測 beforeinstallprompt 事件；當瀏覽器判定網站可安裝時（需 HTTPS、有效的 manifest），會顯示底部提示條。注意：透過 data: URI 內嵌 manifest 時，部分瀏覽器（如 Safari iOS）需手動使用「分享 → 加入主畫面」。若要完整支援 Chrome 安裝提示，建議部署時加入真正的 manifest.json 與 Service Worker。
